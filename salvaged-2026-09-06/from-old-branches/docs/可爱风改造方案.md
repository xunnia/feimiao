# 轻记 · 可爱风改造方案

> 本文档是「轻记 QingJi」安卓版从「极简工具风」转向「可爱风」的完整设计与实施方案，
> 由用户与编排者多轮讨论收敛而成。**这份方案推翻了 `CLAUDE.md` 里原来的「极简工具路线 / 不要可爱风」决策**——
> 以本文档为准。竞品参考：咔皮记账（商汤，AI 原生记账，半年百万用户）。

---

## 一、总方向

- **从「极简工具风」转向「可爱风」**（用户明确决定，推翻原 CLAUDE.md「走 A 极简工具路线 / 不要可爱风」）。
- 差异化锚点：用户**自家的蓝白英短猫**当吉祥物，比竞品咔皮的「卡皮巴拉水豚」更有故事、也避免撞形象。
- 架构上**学咔皮**：无底部 Tab 栏，单主页 + 左上角抽屉；但抽屉与输入框**对齐 Claude** 的气质（与现有 Claude 风输入框一脉相承）。

## 三、整体架构

**无底部 Tab 栏，单主页 + 左上角抽屉**（学咔皮）。记账与查账统一靠首页底部的聊天式输入框。

## 四、主页（首页）

**顶栏**
- 左上角：Claude 风**侧栏面板线性图标** → 打开抽屉（不是三横杠 ☰）
- 右上角：**长条搜索栏**（占满剩余宽度，搜账单/备注/金额）
- ❌ 不放账本切换（账本切换移至抽屉）

**顶部大卡片（折叠吸顶）**
- 滚动行为：下滑 → 缩成迷你吸顶条 `结余 ¥X · 预算 X%`；上滑 → 复原大卡片。
- 收支 + 预算**合并为一张卡、不切换**：
  - 左·收支：主数 = 本月结余（正负变色）；小字 ↑收入(金) / ↓支出(灰)
  - 右·预算：环形进度 + 百分比 + 已用/预算 + 剩余；正常蓝灰、超支变橙
- 🐱 趴卡片右上角：预算正常时招手、超支时捂脸（一眼知超没超）
- 中间竖线分隔，左右各半

**明细列表（突出「日」、弱化「笔」，与咔皮相反）**
- 日期行：当日「支/收」汇总 = **大号加粗分色**（支出深、收入金）
- 单笔行：金额 **小号中性灰**，不抢戏

**底部输入框**：见第六节（核心重构）。

## 六、记账查账聊天面板（底部输入框核心重构）

> 参考咔皮的「记账查账」聊天面板，但做得更顺。**当前实现是「输入→跳独立全屏页」，要改成就地聊天面板。**

- **形态**：点输入框 → 从底部升起一个**可拖拽聊天面板**（半屏，可上拉全屏、下拉收回），背景是首页半透明。不再跳独立全屏页。
- **历史可见**：面板里是聊天流，往上滚能看历史交互（记过的、问过的）。
- **顶部**：猫头像 +「喵助手」+ `⇄ 手动记账`胶囊（切数字键盘大卡）+ ✕ 收起。
- **记账 + 查账合一**：一个框两用，AI 判断意图：
  - "午餐32" → 记一笔，回一张**确认卡片**（午餐 ¥32·餐饮，带「撤销」「编辑」）
  - "这周花了多少" → 查账，回**文字答案 + 迷你图表**

### 深度优化清单（全部纳入实现）
**记账体验**
- 记账结果做成**卡片消息**回到聊天流，可一键**撤销/编辑**（消除「怕记错」焦虑）。
- **多笔确认**：一句多笔时回「N 笔待确认」卡，可逐笔勾选/改/删再入账。
- **澄清式追问**：识别不到金额/分类时 AI **反问**而非瞎记。
- 记成功强反馈：猫举钱袋蹦出 + 轻震动。

**语音（重点，治本）**
- 修录音 bug（当前「语音没录到声音」：查录音权限 / `speech_to_text` 是否真 start / 长按手势）。
- 关键改动：语音识别结果**先填进输入框让用户校对，再点发送**（不要松手直接发——避免识别错误直接记错）。
- 长按时**实时显示识别文字**（partial result）。

**对话质感**
- AI 回答**流式打字** + 猫「托腮思考」动画。
- 空态/占位给**快捷气泡**（记一笔早餐 / 本月花了多少 / 最大一笔支出），轮播「猜你想问」。
- **上下文记忆**：知道当前账本/月份，追问「那上个月呢」能接住。

**健壮性**
- **离线降级**：没网/没 Key 时记账走本地规则解析照记（提示「先本地记下啦」）；查账类提示需联网。
- **历史持久化**：聊天记录存本地（建议只留近期/当天，避免膨胀）；**真实账目永远写进 transactions 表**，聊天只是交互层。

## 七、喵助手

AI 的统一入口与人格。抽屉「喵助手」进入 → 顶部**自动生成本月消费分析报告**（文字版）+ 下方**对话追问**。底部输入框的「问喵助手」是快捷入口，问一句直接跳进喵助手对话。复用 DeepSeek（不用 Claude——国产便宜、国内直连、中文好），喂入统计数据。

## 八、统计页（升级，对齐咔皮）

- 顶部分段：**周 / 月 / 年 / 自定义**（现仅月/年）。
- **三栏汇总**：支出 / 收入 / 结余，分色（支出中性、收入金、结余正负变色）。
- **支出分类构成**：环形图 + 中间总额 + 下方分类排行（进度条 + **笔数** + 点进明细）。
- **每日趋势**柱状图（支出/收入/结余切换）。
- ⭐ **单笔支出排行**（最贵的几笔单独排名，新功能）。
- 柔色马卡龙配色 + 圆角；可加「猫猫锐评」一句话。

**拍照/截图记账·多模态方案（已定，2026-06-14）**
- **AI 服务商做成设置里可切换**：DeepSeek / 小米 MiMo / 其他。三家都兼容 OpenAI 格式，`llm_entry_parser.dart` 已是 OpenAI 兼容 HTTP，切换基本不改架构。文字记账继续用便宜稳的（DeepSeek），图片记账用支持视觉的服务商。
- **本地 OCR 兜底**：账单截图/小票本质是"文字图"，优先用**手机本地 OCR**（Google ML Kit，免费离线）抠出文字 → 再喂文字模型解析。这样图片记账**零成本、不依赖网络**，且对支付宝/微信账单这类清晰文字最准。
- **多模态模型兜底**：拍实物、复杂版面等本地 OCR 搞不定的，再上多模态模型（小米 MiMo V2.5 原生全模态且便宜；DeepSeek V4 也有识图模式但当时还在灰度）。
- 背景：DeepSeek 早期纯文本不支持图片；2026 年起 DeepSeek V4 加了识图、小米 MiMo V2.5 原生全模态并大降价，故采用"可切换服务商 + 本地 OCR 兜底"的弹性方案，到 M7 实测哪个准又便宜就用哪个。
