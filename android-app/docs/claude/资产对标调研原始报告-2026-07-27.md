# 国际党标杆资产管理调研（选定：MoneyWiz / Kubera / YNAB）

选择说明：Wallet by BudgetBakers 官网与评测中资产侧信息薄弱（主打预算+银行同步，净资产/投资/负债功能公开资料几乎查不到），信息完整度不足，弃选。以下三家信息最全。

---

## 1. MoneyWiz（SilverWiz，"全能型记账+资产"天花板）

### ① 资产管理核心功能清单
- **账户体系**：现金/支票/储蓄/信用卡/投资/贷款(Loan)多类型账户；账户可选是否计入净资产（Net Worth 在账户列表顶部实时汇总，可排除指定账户）
- **净资产**：账户注册页直接显示总净资产；30+ 可自定义报表含净资产走势
- **投资账户**：支持股票、期权、债券、ETF、基金、外汇、加密货币，甚至 pre-IPO/pre-ICO 非上市资产；持仓自动刷新行情价、历史绩效分析；理论上"一切可买卖的证券资产"（美股/港股/外汇/基金）都能记（少数派教程覆盖基金定投、美股记录）
- **负债/贷款账户**：内置**摊销模型**——建贷款账户后自动生成"本金+利息"两分类的拆分计划交易，按摊销公式算月供，只有本金部分冲减贷款余额；支持无息贷款
- **多币种**：完整多币种支持+汇率自动刷新，外币账户按实时汇率折算进净资产
- **银行同步**：4 家数据供应商聚合 40,000+ 银行/55 国，自动拉流水、实时余额、AI 归类（不含中国大陆银行）

### ② 最被称道的资产功能点
- **"投资持仓自动计入净资产"的一体化**：记账、预算、投资、贷款在同一账本里，净资产= 全账户+持仓市值实时汇总，这是它被少数派称为"逻辑/功能/交互综合评分最高的个人记账系统载体"的核心原因
- 贷款账户的自动本息拆分（对手工记房贷的用户是刚需级体验）

### ③ 明显短板
- **投资模块深度不足且行情源不稳**：少数派有用户明确建议"规避在 MoneyWiz 里管理投资账户，只记本金"——行情覆盖（尤其 A 股/场外基金）和成本核算不如专业工具
- **多端同步有翻车史**：用户报告同步后交易重复/错乱
- 订阅制价格偏高；银行同步对中国用户无效
- 无资产配置比例分析、无财务自由进度这类"财富视角"功能——它本质仍是记账软件的资产延伸

---

## 2. Kubera（纯净资产追踪器，"净资产管理顶尖水准"的参照系）

### ① 资产管理核心功能清单
- **全资产聚合**：对接多家聚合器连接 20,000+ 全球银行/券商；股票/ETF/基金（全球主要交易所行情）；加密货币/DeFi/NFT/质押借贷；另类投资、私人股权、LP 份额（与 Carta 集成）；房产、车辆、珠宝、手表等实物资产
- **实物资产估值接口**：**房产填地址或 Zillow 链接自动取市场估价（仅美国）；车辆填 VIN 码自动取市价；域名接 EstiBot 估值**；另有 AI 估价工具处理其他实物
- **多币种**：跨币种/跨境财富管理，任意币种资产统一折算净资产
- **回报分析**：自动算每笔投资的 **IRR（内部收益率，考虑多次出入金和时间）**，并**对标 S&P 500、道指、AAPL、BTC 等基准**，直接告诉你主动管理有没有跑赢指数
- **资产配置**：Portfolio 配置比例报告；Club Benchmarks（和同类人群对标）
- **前瞻**：Fast Forward 动态情景规划（按假设推演未来净资产曲线）；现金流/流动性预测
- **传承与安全**：Dead Man's Switch（账户长期不活跃自动把财务清单交给受益人）、文档保险箱、财富证明生成、嵌套组合（信托/LLC 结构）、细粒度分享权限、AI 导入（CSV/截图识别建仓）

### ② 最被用户称道的资产功能点
- **"什么都能塞进一张资产负债表"**：银行+券商+币圈+房+车+域名+私募，一个仪表盘出净资产，评测普遍称其为"最全能的净资产追踪器"（已追踪个人资产超 $121 亿）
- Dead Man's Switch 数字遗产是独一无二的记忆点；IRR 对标指数也被多篇评测点名"真有用"

### ③ 明显短板
- **完全没有记账/预算/支出分析**——它只管"存量"，不管"流量"，需要搭配别的记账工具
- 贵：$249/年，无免费版
- 房/车估值接口**仅限美国**；中文互联网几乎无讨论（知乎/少数派查不到成篇评测），对中国资产（A 股、银行）无直连

## 3. YNAB（预算派代表，资产侧是"反面参照+一个亮点"）

### ① 资产管理核心功能清单
- **账户二分**：预算账户（日常资金）vs **Tracking 账户**（投资/房产等只记余额、不参与预算，手动更新市值）
- **净资产报表**：Reflect/Net Worth 报告，按月画资产-负债-净资产曲线，可自定义
- **贷款账户（亮点）**：Tracking 账户可升级为 Loan 账户，录入利率后自动记息；**Loan Payoff Simulator（仅网页版）**：实时模拟"每月多还 X 元"能省多少利息、提前多久还清——负债摊销+还款规划做成了交互玩具
- 银行同步（美加为主）；无投资持仓/行情功能

### ② 最被称道的资产功能点
- **Loan Payoff Simulator**：把"多还一点省多少利息"可视化，官方口号"看着还债进度推高净资产曲线"，是债务管理侧被引用最多的功能

### ③ 明显短板
- **单账本单币种**：官方不支持多币种，多币种用户只能开多个账本或用第三方 API 插件换算——净资产视角直接残废
- 投资资产只能手动改余额，无行情、无持仓、无配置分析
- 订阅贵（$109/年）且同步以北美为主；对"资产管理"这个命题基本是空白，它的哲学就是只管预算

---

## 综合：净资产管理的「顶尖水准」画像（对照肥喵可借鉴的层级）

| 维度 | 顶尖水准（谁做到的） |
|---|---|
| 多币种净资产 | 任意币种资产实时汇率折算成一条净资产曲线；账户级"是否计入净资产"开关（MoneyWiz、Kubera 都有；YNAB 反例） |
| 投资组合联动行情 | 持仓级记录+自动刷价+市值滚入净资产（MoneyWiz）；再往上是 **IRR 按出入金精算 + 对标 S&P500/BTC**（Kubera 独有） |
| 房产/车辆估值接口 | Kubera：地址/Zillow 取房价、VIN 取车价、EstiBot 取域名价——但全是美国接口；国内 App 可行替代=手动估值+定期提醒更新 |
| 负债摊销计划 | MoneyWiz：贷款账户自动生成本息拆分月供；YNAB：再进一步做成"多还款省息模拟器"（交互最佳） |
| 财务自由进度 | 三家都没有直给的"FIRE 进度条"；最接近的是 Kubera 的 Fast Forward 情景推演（假设收益率/储蓄率推未来净资产） |
| 资产配置比例分析 | Kubera 的组合配置报告+人群对标；MoneyWiz/YNAB 均无 |

**关键洞察**：国际市场把"记流水"和"管净资产"做成了两个物种——MoneyWiz 试图两者兼得（各有妥协），Kubera 放弃记账专攻存量（做到极致），YNAB 放弃资产专攻预算（只留贷款模拟一个亮点）。对肥喵（已有记账底盘）而言，性价比最高的借鉴顺序：账户级净资产开关+多币种折算 → 负债本息摊销/还款模拟 → 手动估值资产+更新提醒 → 配置比例环图 → IRR 类精算（最后做，依赖行情源）。

# 国内大厂系记账 App 资产管理能力调研（随手记 / 挖财记账 / 薄荷记账）

**选样说明**：按「信息最全 3 个」原则选了随手记、挖财记账、薄荷记账。口袋记账被排除：其资产功能仅有基础账户管理（6 种账户类型、余额调整、账户内流水、账户间转账），2024 年 6 月后基本停更，公开资料里几乎查不到净资产/投资/负债层面的能力，样本价值低。另注：薄荷记账实为个人开发者长期维护的产品（非严格意义大厂），但功能完整度和口碑在这批里最高，照常纳入。

---

## 一、随手记（金蝶系，国内资产模块做得最重的记账 App）

### ① 资产管理核心功能清单
- **账户体系极全**：现金 / 储蓄卡 / 信用卡 / 基金 / 股票 / 银行理财 / 虚拟账户 / 负债账户 / 债权账户 / 投资账户，十余种类型
- **资产-负债-净资产三栏展示**，可点进任一账户看往来明细、逐笔对账
- **信用卡账户**：支持设置额度、账单日、还款日（此功能是后来版本补上的，官方社区曾专门发帖宣传「再也不怕忘记还款」），可配还款提醒
- **借贷中心**：以「借贷对象（人）」为视角管理债权债务，谁欠我、我欠谁、收/还金额一目了然；支持借贷/代付/报销等专门转账类型
- **投资中心**：本土化亮点，支持国内基金/股票的申购赎回记录、**联网查实时净值**、自动算投资回报
- **「不计入资产」开关**：储值卡、公交卡等不可变现资产可从净资产/现金流中剔除
- 房贷类负债：靠「负债账户 + 周期账（每月固定还款）」组合实现，无专门房贷向导（未查到独立房贷模块）
- 18 种数据报表 + 超级流水（按分类/账户/项目/商家自定义汇总查询）

### ② 最被用户称道的资产功能点
- **借贷功能**——少数派长文作者原话评价为「市面上记账软件中最为好用的，没有之一」（按人管理欠款/借出是核心）
- **「不计入资产」设置**——把不可变现资产剔出现金流，重度用户视为专业性标志
- 投资中心联网净值（同类 App 少见的本土化能力）

### ③ 明显短板
- **P2P 黑历史**：曾代销拍拍贷/人人贷等 P2P 产品，暴雷后有用户被「强制确权、扣已得利息」（知乎有维权帖），品牌信任严重受损
- **广告 + 会员化**：版本迭代后广告多到有用户直呼想卸载，数据导出（Excel）变成会员功能
- **投资账户数据割裂**：投资盈亏能自动记录，但买卖不计入首页账单（少数派横评点名「数据割裂」）；投资中心早期连转账都不支持
- App 体积全场最大、弱网启动极慢；UI 风格陈旧（橙黄配色、半扁平），汇率功能繁琐鸡肋

---

## 二、挖财记账（老牌，2009 年起家，资产定位「钱在哪儿一目了然」）

### ① 资产管理核心功能清单
- 资产 + 负债统一管理，账户账单页逐条对账
- **信用卡管理**：额度、出账日、还款日、**免息期管理**（这点比随手记细）
- **资金计划（现金流预判）**：把信用卡还款、房贷、车贷、房租、水电煤、保险、物业费、借贷还款做成待办，**可统计未来某段时间的固定开支总额**，并逐项提醒
- 借贷账户、投资账户、多币种、账户备注
- 12 个统计维度、29 种报表
- 微信/支付宝/银行 Excel 账单批量智能导入 + 周期自动记账（水电煤、公积金）

### ② 最被用户称道的资产功能点
- **信用卡免息期/还款提醒 + 资金计划**：对多卡、有房贷车贷的用户，「未来 N 天要还多少钱」的现金流视角是其差异化卖点
- 智能预选类别/账户（横评评价「优秀」），导入体验好
- 免费版能用到大多数功能（相对随手记）

### ③ 明显短板
- **会员费贵且卡关键功能**：数据导出要求最高档会员，被 CSDN/知乎用户专文吐槽「逃离挖财」并手工迁移数据
- **改版翻车**：11 年老用户吐槽新版记一笔里「项目」维度直接消失、账户/报销/商家等选项被缩得极小
- 启动越来越慢（弱网尤甚）、功能索要会员越来越多
- 记账流程长：默认滚轮式「时间」选择器而非日期选择器，效率差
- 同样有理财平台黑历史（产品定位重「挖财」轻记账，早年 P2P 时代遗留信任问题）

---

## 三、薄荷记账（个人开发者维护，免费口碑最好，资产功能反而最均衡）

### ① 资产管理核心功能清单
- **账户分组视图**：任意角度给账户分组汇总资产，一个账户可属多组，长按拖动自由排序、可折叠
- **信用卡账户**：额度、出账日、还款日；付费解锁**分期管理**
- **投资账户**：新建时可**绑定股票/基金代码**，随时看盈亏（付费后自动记录盈亏）；股票/基金账户详情页可记买卖、申购赎回、货币转入转出
- **货币基金绑定**：储蓄卡/现金账户可绑货基，**每日收益自动同步入账**（同类少见）
- 借贷账户、多币种、账户备注、结余预算、多人同步账本、账单导入
- 无广告；免费版覆盖约 90% 功能，VIP 约 30 元/年

### ② 最被用户称道的资产功能点
- **投资账户绑定行情自动算盈亏 + 货基每日收益自动入账**——以极低价格给到「随手记专业版」级别的投资追踪
- 账户分组自由汇总资产（想按「流动/固定」「我的/家庭」随便切视角）
- 「无广告、免费够用、便宜」本身就是相对大厂的最大口碑点

### ③ 明显短板
- 账户管理界面简陋、图标不好看，自定义程度低（分类不可自定义的吐槽）
- 版本大改频繁，老用户学习成本高
- 「先输金额再选类别」的记账流程部分用户不适应；安卓常驻通知栏受系统限制
- 个人开发维护，持续性依赖单人（用户选型时的潜在顾虑）；净资产历史走势图能力未查到明确资料

## 四、横向结论（给肥喵的增量参考）

**大众用户实际高频使用的资产功能（三家评测/评论区反复出现的就这几个）**：
1. **账户余额 + 账户内流水对账**（最基础也最刚需，口袋记账只做了这个也活了很多年）
2. **信用卡三件套：额度 / 账单日 / 还款日 + 还款提醒**（挖财免息期、薄荷分期是进阶加分项）
3. **借贷/欠款按「人」管理**（随手记借贷中心是被点名「没有之一」的功能）
4. **房贷 = 负债账户 + 每月周期账**，三家都没有独立房贷向导，用户用组合方案也够用
5. **「不计入资产/不计入净资产」开关**（储值卡、公交卡剔除，重度用户强需求）

**避坑清单（大厂做了但用户不买账/反噬的）**：
- **理财/贷款变现**：随手记、挖财都靠 P2P 代销赚钱，暴雷后成为品牌最大污点，评论区至今提及「黑历史」——记账 App 里塞理财入口是负资产
- **数据导出锁会员**：随手记、挖财都因此被写「逃离」教程；数据自由是记账用户的底线
- **广告轰炸 + 功能逐步会员化**：随手记广告被骂到用户扬言卸载
- **投资模块与账单割裂**：随手记投资买卖不进首页账单，被横评点名；投资账户必须与主账本资金流打通才有意义

## ③ 普通人 vs 投资党的需求分野

**普通人（非投资客）**：要的是"省事+安全感"。①不想逐笔记流水，接受"定期更新余额"的快照式盘点（"每个月4000生活费，不记账，不超就行"）；②核心问题只有"我总共有多少钱、欠多少"，看重信用卡还款日/额度、借出去的钱、攒钱目标；③对广告和收费极度敏感（"节俭"人群，收费即卸载），怕小厂倒闭丢数据；④对几块钱的对账误差都会烦躁，需要"调整余额"这种一键抹平的入口；⑤延伸需求是物品资产（这件东西每天摊多少钱），偏生活感而非金融感。

**投资党**：要的是"精确+全谱系"。①多账户（券商/基金/加密/贵金属/海外）独立管理+分组汇总，转入转出必须精确记录，否则收益率就算错（有知有行调研）；②要收益率曲线、资金加权/年化收益率、与业绩基准对比，不只是余额数字；③要行情自动刷新和多币种汇率，手动更新净值不可接受；④愿意付费、愿意上Excel/Beancount复式记账，最大痛点反而是历史数据导入成本；⑤对每笔消费流水无所谓，"只记重要变动"。

**共同语言是净资产曲线**：两类人都用它当"财务体检表"；分野在颗粒度——普通人到"账户余额"为止，投资党要下钻到"每个持仓的成本与收益率"。对肥喵的启示：资产模块以"余额快照+净资产曲线+信用卡/借出提醒"打普通人，行情联动类留作可选层，别把投资功能做成必经路径。

- **资产负债表（会员，免费体验6个月）**：总资产/负债/净资产三段结构；文档明确解释「净资产变动 ≠ 首页月结余」的口径差（报销、不计入账户会造成两者不同）。
- **资产曲线（会员，免费体验6个月）**：**不是定时快照，而是由账单反推的月末余额**——初始金额+每月流水累加得出每月末余额，按月画单资产趋势线；导入/漏记/平账会导致偏差，**支持手动校正某个月的余额**。
- **债务管理**：借入(Debt)/借出(Loan)两类，记债权人/金额/关联账户/日期；未结清/已结清两状态，结清自动隐藏；**还款超出本金部分自动记为利息**。
- **周期记账（免费2条/会员80条在执行）**：支持支出/收入/转账/**还款**四类，粒度「每n天/周/月/年」；关联的账户/账本/分类被删则任务失效标记结束；改设置只影响未来账单。
- **分期管理（会员，免费2条）**：花呗/信用卡分期，每月固定时间自动记一笔分期支出，生成后可二改可删，但**分期任务本身建了不能改**。
- **报销管理**：设置里开开关→记账时标「报销」；报销管理页勾选→填入账信息→变「已报销」并生成一笔与原单**关联的「报销入账」账单**；一笔待报销**最多可分10次报销入账**、可取消入账回退状态；统计页顶部有「未报销/已报销」汇总项。
- 其他：存钱计划、多设备同步、自动备份。

② 最被用户称道的资产功能点

- 横评类文章的共识：「**资产管理功能比大部分竞品完整，信用卡、花呗、基金账户都可以加进来**」（搜狐6款App实测）——账户类型覆盖广 + 信用卡账单日/免息期这套是它相对鲨鱼/一木等的主要差异点。
- 「免息期最长的卡」横幅是少见的「帮你做决策」型资产功能（不只展示、还告诉你今天刷哪张）。
- 报销闭环完整（多次入账、可回退、进统计口径）是知乎/少数派评测里常被点名的「接地气」功能。

③ 明显短板

- **零智能化**：无AI/语音/截图识别（搜狐实测原话「干净到没有任何智能化功能」），纯手动工具。
- **资产负债表、资产曲线、分期、周期账(>2条)、多账本全是会员墙**；免费用户只有基础账户管理。
- 资产曲线靠账单反推而非真快照，数据一乱（导入/漏记）就偏，需要手动校月末余额——文档自己承认这个局限。
- 投资账户只是「一种账户类型」，**无持仓/市值/收益率跟踪**（「三无」里的「无理财」是刻意为之）；实物资产（房/车）无专门支持，未查到。

二、咔皮记账（商汤系→上海禹幻科技，AI记账赛道TOP1，百万+用户，肥喵的视觉对标）
━━━━━━━━━━━━━━━━━━

① 资产管理核心功能清单（来源：App Store 介绍/更新日志、应用宝、第三方下载站版本日志）

- 定位是「AI原生财务助手/个人CFO」，**资产模块是记账的配角**：App Store 副标题挂着「资产管理·存钱」，但介绍正文只有一句「把你的资产账户管理的明明白白」，无展开。
- **资产账户**：AI记账时可自动识别并关联到资产账户；账单导入支持**批量修改账本和资产账户**（v0.9.01）；资产账户支持**拖拽自由排序、置顶特别关注的账户**（v0.9.30）。
- **余额变动明细 + 账户时间轴**：新增「余额变动明细」视图，每笔余额变化可查；资产账户时间轴样式优化，可翻历史流水（版本更新日志）。
- **借贷账户**：支持借入/借出，可在账户上直接「还款」「记账」「追加借入/借出」（v0.9.30「借贷账户完善」）。
- **攒钱计划（特色）**：v0.8.60 上线，**与支付宝小荷包打通「真攒钱」**——选系统推荐目标（如旅游基金）或自定义，设每日/每周攒钱额，系统自动执行。
- 周边：无限多账本（免费）、AI智能预算+超支预警、AI理财助手（对话式收支分析+图表）、账本共享、桌面小组件。
- **信用卡账单日/还款日/免息期管理：未查到**（官方介绍、更新日志、评测均无提及；搜索结果里出现的是卡牛/卡喵等专门App）。
- **净资产/资产负债视图、净资产曲线：未查到明确证据**（有总资产展示的推测，但无任何官方或评测文字确认净资产/负债口径）。
- 实物资产、多币种：未查到。

② 最被用户称道的点（资产相关口径）

- 用户称道的几乎全在**记账入口**而非资产：AI识别准、语音/截图/敲手机背面记账、卡皮巴拉可爱UI「记账比花钱还上瘾」（腾讯新闻/新浪对话稿）。App Store 4.8分/5.1万评价，好评关键词是「颜值+多样免费功能」。
- 资产侧唯一有记忆点的是**攒钱计划×支付宝小荷包**——把「记目标」变成「真转账攒钱」，这是钱迹等本地工具做不到的（需要账号+联运）。
- 对肥喵的启示：咔皮证明了可爱风App的资产模块**靠「账户时间轴+余额变动明细+置顶排序」这种轻展示就够用户用**，重财务概念（负债表/免息期）它根本没做。

③ 明显短板

- **资产深度到「账户列表+流水」就停了**：无信用卡账期管理、无净资产曲线/负债表（未查到）、无分期/报销专门闭环（未查到）——它把资源全押在AI入口上。
- **算不准数**：App Store 差评原话「一个记账软件算不清楚数是最愚蠢的」，账户计算错误、收支分类混乱被点名——资产余额可信度是硬伤。
- **强依赖账号+云端**：「每次进去都要重新登陆，还一直卡」「网络卡顿登录不进去」；对比钱迹/肥喵的纯本地是明显劣势。
- 商业模式软肋：高级AI功能限免后转会员（现玩「记一天送一天会员」拉活跃），手动记账体验一般、高级功能入口深（搜狐实测）；现金/非扫码用户不好用。
- 近期改版「UI变极简冰冷风」遭老用户吐槽（可爱风人设本身就是留存资产，改掉会掉粘性——对肥喵是个警示）。

对肥喵的要点提炼
━━━━━━━━━━━━━━━━━━
1. 钱迹资产模块的护城河 = 信用卡账期/免息期 + 资产负债表/资产曲线 + 报销/分期/债务全闭环；其中「免息期最长的卡」横幅、「报销可多次入账」、「资产曲线可手动校月末余额」三个设计细节值得直接借鉴。
2. 钱迹的资产曲线是「账单反推月末余额」不是定时快照——肥喵若做净资产曲线，可以用真快照（余额审计点）做差异化，规避钱迹「数据一乱曲线就歪」的痛点。
3. 咔皮（视觉对标）资产深度很浅：账户列表+余额变动明细+时间轴+借贷账户+攒钱计划即止，无账期无净资产——肥喵在资产深度上超过咔皮很容易，真正的对标线是钱迹。
4. 咔皮唯一资产亮点「攒钱计划×支付宝小荷包」依赖联运，本地App做不了同款，但「目标+自动划拨到虚拟存钱账户」的本地模拟版可做。
