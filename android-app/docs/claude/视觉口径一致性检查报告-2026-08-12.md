## 二、金额显示的币种规则 ⚠️ 存在混淆风险

**问题级别：用户会困惑（P1）**

### 当前实现

`MoneyFormat.string()` 默认币种 `CNY`，显示 `¥`。外币需显式传 `currencyCode` 参数。

### 已正确处理币种的位置 ✅

- **物品资产详情页**（`physical_asset_detail_page.dart:159/165/186/1197/1211`）
  - 所有金额都传递了 `currencyCode: current.currencyCode`

### 未传递币种、统一显示 ¥ 的位置 ⚠️

#### 2.1 净资产总览卡（`asset_overview_cards.dart`）

**位置**：228 行净资产金额、360 行各项指标（资金资产、计入物品、资金净值、总负债、总资产）

**问题**：如果外币账户计入净资产，显示的是换算后的 CNY 等值，但**没有任何提示告诉用户这是换算值**。用户可能误以为是原币种金额，或者不知道汇率是哪天的。

**影响**：拥有外币账户的用户会困惑「我 USD 账户明明只有 $500，怎么总资产显示 ¥3500？」

#### 2.2 资产配置环图（`asset_overview_cards.dart:458/501`）

**位置**：环图中心"总资产"金额、图例中各分类金额（流动资金、投资余额、权益资产、计入物品）

**问题**：混合了不同币种物品后统一显示 ¥，无法区分哪些是 CNY、哪些是换算后的外币。

#### 2.3 所有预算相关组件

**位置**：
- `monthly_pace_card.dart`：平均、本月支出、分类金额
- `budget_special_tracking_ui.dart:529/547/693`：专项追踪已用/剩余金额
- `statistics_view.dart`：统计页所有金额

**当前影响**：预算目前只支持 CNY，暂无混淆。但若未来支持多币种预算会有问题。

### 建议修复方向（分优先级）

| 优先级 | 位置 | 修复方案 |
|--------|------|----------|
| **P1** | 净资产总览卡 | 标题加标注「净资产（按 CNY 计）」或「净资产 ¥」明确币种 |
| **P1** | 资产配置环图 | 中心金额后加「CNY 等值」提示 |
| P2 | 物品资产列表 | 混合币种时在金额后显示原币种标识，如「¥350（USD $50）」 |
| P3 | 预算组件 | 待多币种预算支持时一并处理 |

**统一规则建议**：
- **汇总类金额**（净资产、总资产、总负债）：明确标注基准币种「按 CNY 计」
- **单项金额**（单个账户、单个物品）：显示原币种符号
- **混合展示**（同时有 CNY 和外币）：原币种 + 等值换算，如「$50（≈¥350）」

## 三、百分比和进度的四舍五入 ⚠️ 存在割裂

**问题级别：中等（用户体验割裂 P1，代码风格 P2）**

### 3.1 进度条视觉与文本割裂 ⭐ 最需修复（P1）

#### 问题 A：服役进度条（`physical_asset_detail_page.dart:1117/1140`）

```dart
final pct = (ratio * 100).toStringAsFixed(0);  // 文字：四舍五入整数
Text('服役 $pct%${exceeds ? ' · 已超期' : ''}')
LinearProgressIndicator(value: ratio)  // 进度条：精确小数值
```

**案例**：`ratio = 0.995` 时
- 文字显示：「服役 100%」（四舍五入）
- 进度条视觉：只到 99.5% 处
- **用户感知**：「明明说 100% 了怎么条子没满？」

#### 问题 B：预算进度环图（`statistics_view.dart:2321/2340`）

```dart
final pctText = '${(ratio * 100).round()}%';  // 文字：四舍五入
BudgetProgressRing(value: ratio.clamp(0.0, 1.0))  // 环图：精确值
```

同样的割裂问题。

### 3.2 百分比精度不统一（代码风格，P2）

**分类占比 — 混用两种写法（功能等效）**：
- `monthly_pace_card.dart:535`：`(item.share * 100).round()` 
- `statistics_view.dart:2565/3016`：`(item.share * 100).toStringAsFixed(0)` 
- `home_view.dart:374`：`(item.share * 100).round()` 

**负债率 — 单独保留一位小数**：
- `asset_overview_cards.dart:521`：`(liabilityRate * 100).toStringAsFixed(1)` = "45.3%"

### 完整列表

| 位置 | 代码 | 精度 | 割裂风险 | 优先级 |
|------|------|------|---------|--------|
| 服役进度文字 | `physical_asset_detail_page.dart:1117` | `.toStringAsFixed(0)` | ⚠️ 是（进度条用精确值） | P1 |
| 预算环图文字 | `statistics_view.dart:2321` | `.round()` | ⚠️ 是（环图用精确值） | P1 |
| 月进度分类占比 | `monthly_pace_card.dart:535` | `.round()` | 无（只有文字） | P2 |
| 统计页分类占比 | `statistics_view.dart:2565/3016` | `.toStringAsFixed(0)` | 无（只有文字） | P2 |
| 首页分类占比 | `home_view.dart:374` | `.round()` | 无（只有文字） | P2 |
| 存钱目标进度 | `savings_goals_view.dart:463` | `.round()` | 无（进度条另算） | P3 |
| 资产配置负债率 | `asset_overview_cards.dart:521` | `.toStringAsFixed(1)` | 无（只有文字） | P3 |

### 建议修复方向

#### 方案 A（推荐）：文字跟随进度条精确舍入

```dart
// 服役进度示例
final displayRatio = (ratio * 100).round() / 100.0;  // 四舍五入到整数后再除 100
final pct = (displayRatio * 100).toInt();
Text('服役 $pct%')
LinearProgressIndicator(value: displayRatio)  // 进度条也用舍入后的值
```

**优点**：文字和视觉完全一致  
**缺点**：进度条会有 0.5% 以内的跳变（用户基本无感）

#### 方案 B：统一代码风格

将 `.toStringAsFixed(0)` 统一改为 `.round()`，或反之。保持功能不变，只是代码更一致。

#### 方案 C：特殊标注

99.5%~100% 之间的进度，文字显示「99%」而非「100%」，避免「显示 100% 但进度条没满」的割裂。
