## 三、外币负债修复详解

### 问题原因
```dart
// 旧代码：lib/data/app_repository.dart
final cnyEquiv = acct.balanceMode == 'debt'
    ? Decimal.zero  // debt 账户不计入 CNY 等价
    : MoneyFormat.toCNY(acct.balance, acct.currencyCode);

cashInCNY += cnyEquiv;  // ❌ 外币 debt 账户余额也加进来了
```

**根本原因**：
- `debt` 账户余额是**负债本金**（正数）
- 转 CNY 时被当作资产加进 `cashInCNY`
- 例如：USD debt 账户 $1000 → CNY 等价 ¥7000 → 错误地增加净资产

### 修复方案
```dart
// 新代码
if (acct.balanceMode == 'debt') {
  // debt 账户余额是负债本金，不参与 cashInCNY 累计
  continue;
}

final cnyEquiv = MoneyFormat.toCNY(acct.balance, acct.currencyCode);
cashInCNY += cnyEquiv;
```

### 测试覆盖
新增 4 个测试用例（`test/foreign_currency_liability_test.dart`）：
1. USD 负债账户不计入 CNY 净资产
2. EUR 负债账户不计入 CNY 净资产
3. 混合 CNY + USD(netWorth) + EUR(debt) 正确计算
4. 纯负债账户（3 个外币 debt）净资产为零

全部测试通过 ✅

class PercentFormat {
  /// 返回四舍五入的整数百分比（用于文本显示）
  static int toInt(double ratio) => (ratio * 100).round();
  
  /// 返回文本显示用的整数百分比，并确保进度条值同步
  static ({int display, double barValue}) forProgressBar(double ratio) {

}
