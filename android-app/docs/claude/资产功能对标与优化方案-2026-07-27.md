# 资产管理功能对标与优化方案（2026-07-27）

> 背景：v209（P0/P1/P2 资产 UI 三批完成）发布后，用户问「我们的资产管理到顶尖水准了吗？对比有数等，怎么优化」。
> 依据：6 路调研（有数/钱迹+咔皮/MoneyWiz·Kubera·YNAB/随手记·挖财·薄荷/用户之声/自身盘点），原始报告存档见本文末注。
> **状态：方案待用户拍板，未动代码。**

## 一、诚实结论：还没到顶尖，但底盘是独一档

**已是第一梯队甚至独一档的（别人没有或做不到）：**
1. **数据诚实性体系**：质量口径全链路（partial 不冒充完整、待确认/历史推定明示、审计链、快照 causes/scope 断代）——所有竞品都没有这个概念。
2. **真快照净资产曲线**：钱迹的资产曲线是「账单反推月末余额」，导入/漏记就歪、要手动校月；我们是每日 computed 快照+可信起点+断开点标注，天生规避它文档里自认的痛点。
3. **实物资产全生命周期**：日均持有成本/持有天数/保值率/使用次数/每次成本/保修提醒/出售净到账/退款分摊审计——「有数」App 的全部核心卖点（日均成本、服役状态、卖出盈亏）我们已覆盖且更深（它无金融侧，我们金融+实物一体）。注：调研实锤「有数」是物品维度 App，不是净资产管家，含金量被高估。
4. **对可爱风赛道**：咔皮资产深度=账户列表+流水即止，我们早已越线。**真正的对标线是钱迹（国民级）和 MoneyWiz/Kubera（国际级）。**

**离顶尖的差距（按用户价值排序）：**
| # | 缺口 | 谁做到了 | 用户声量 |
|---|---|---|---|
| 1 | **信用卡账期三件套**：账单日/还款日/免息期+还款提醒 | 钱迹（免息期最长卡横幅）、挖财、薄荷、随手记 | 用户之声 TOP4，普通人最高频 |
| 2 | **借贷按「人」管理**：谁欠我/我欠谁、部分还款、利息 | 随手记借贷中心（被评「没有之一」）、钱迹债务 | 次高频；我们只有 loanOut 权益，无对象视角、无借入 |
| 3 | **负债摊销/房贷**：本息拆分月供、还款计划、「多还省息」模拟 | MoneyWiz 摊销、YNAB 模拟器 | A5 负债单一真相源欠账正好一起还 |
| 4 | **资产配置比例分析**：结构环图/占比/流动性 | Kubera；国内都很弱 | 我们 breakdown 数据现成，只差可视化 |
| 5 | **懒人快照盘点模式**：不记流水、定期更新余额 | Percento/多少资产（专门 App） | 用户之声 #8，我们校准锚点是现成地基 |
| 6 | 投资持仓/行情/收益率 | MoneyWiz/薄荷（绑代码自动盈亏）/Kubera(IRR) | 投资党需求；与纯本地有张力 |
| 7 | 多币种折算净资产 | MoneyWiz/Kubera | 现状 legacy 外币只读、明示未含——诚实但不折算 |

## 二、分批方案（建议顺序 A→B→D→C）

### A 批「普通人三件套」（预计 2-3 天，DB 有改动，价值最高）
1. **信用卡账期管理**：credit/loan 账户扩展 liabilityProfile（账单日+还款日+额度）；免息期计算引擎（纯本地纯逻辑，可单测）；资产页「最近要还」卡（N 天内到期的还款，按日排序）；还款动作=转账+标记核销；本地通知提醒（复用定时记账的通知通道）。彩蛋位：学钱迹「今日刷哪张免息最长」横幅（做成可关）。
2. **借贷对象化**：借入/借出统一按「人」聚合视图（数据层：receivable 加 counterparty 已有字段强化+新增借入类型挂负债），部分还款/收回时间线，超本金部分自动记利息（学钱迹）。人情债也是账——贴可爱路线做「TA 和我的往来」页。
3. **房贷/大额分期向导**：负债账户+周期还款一键搭（每月 N 日自动记转账/支出），本息拆分做**可选**（默认不拆，勾选年利率才拆——守简单可爱路线，不逼用户学财务）。顺手把 **A5 负债单一真相源**欠账清了。

### B 批「净资产补完」（预计 1-2 天）
1. **A3b verified-checkpoint 纠错**（superseding/revoked，交接文档老欠账）。
2. **资产配置环图**：总览加「资产结构」环形图（流动/投资/实物/权益/负债占比），数据现成，低成本高感知。
3. **懒人盘点模式**：可开关的「每月盘点提醒」（本地通知）→ 一键进「逐账户核对余额」流程（复用校准锚点+verified checkpoint），完成给成功猫。把我们最强的「真快照」优势变成普通用户摸得到的仪式感。
4. 净资产曲线增强：区间切换（3月/1年/全部已有?核对补齐）+成分堆叠视图（可选）。

### C 批「投资可选层」（押后单独拍板，与纯本地有张力）
- 投资账户持仓化：手动记份额/净值，自动算成本与简单收益率（**不联网行情为默认**）。
- 行情联动做 opt-in（如接免费基金净值源或让用户用自己的 key），绝不做必经路径——用户之声明确：普通人到余额为止，行情是投资党可选层。
- IRR/基准对标（Kubera 级）最后再说。

### D 批「差异化小件」（每件半天内，穿插做）
- 物品「服役进度条」+卖出盈亏复盘卡（把已有数据可视化，正面迎击「有数」的记忆点）。
- 净资产里程碑（首破 X 万）成功猫庆祝；核对连续 N 月徽章。
- 免息期横幅（依赖 A1）。

## 三、避坑护栏（调研实锤的反面教材，铁律）
1. **绝不塞理财推销/贷款变现**——随手记/挖财 P2P 暴雷是品牌最大污点。
2. **数据导出永远免费**——「导出锁会员」是用户写「逃离」教程的头号原因。
3. **投资/行情绝不做必经路径**——普通人模式默认干净。
4. **改版只加不减维度**——挖财砍「项目」维度流失 11 年老用户；咔皮改极简风被老用户骂（可爱人设本身是留存资产）。
5. **资产数必须算得准**——咔皮「算不清数」是其资产模块头号差评；我们的诚实性体系就是护城河，任何新功能不许破坏质量口径。
