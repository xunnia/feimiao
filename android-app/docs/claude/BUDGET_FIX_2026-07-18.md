# 2026-07-18 预算周期冲突修复交付记录

## 问题

新建预算默认允许从下周期开始。用户随后选择“本周期生效”时，旧实现把尚未开始的未来主计划也当成当前重叠，导致首页显示没有预算、设置页却禁止保存。

## 修复

- 当前周期新计划遇到尚未开始的未来主计划时，自动设置 `end_day` 为未来计划开始前一天；未来计划、历史账单和历史预算不删除、不改写。
- 只有真正覆盖待创建周期起点的主计划才会阻止重复创建，并提示调整现有计划或选择下周期。
- 归档尚未生效的计划写入空结束日，避免生成早于开始日的非法区间。
- 已归档周期仍参与历史覆盖保护，避免归档后再次创建同周期主计划造成 resolver 冲突。
