# UI 对比图交付规范

凡是调整了 UI 的批次，交付时必须同时提供：

1. 调整前原始截图（保留在测试基线或 `test/failures`，不覆盖）。
2. 调整后当前截图（来自最新截图回归输出）。
3. 调整前后左右并排的对比图。
4. 在两侧相同位置用编号框标出改动，并在图底部写明每个编号对应的调整内容。
5. 多个页面再额外提供一张总览联系图，方便快速确认本批范围。

对比图只允许拼接真实截图，不使用概念图或 AI 生图替代。原始截图不得被标注层覆盖；对比图统一输出到：

`android-app/outputs/ui_comparisons/<日期>/`

本目录的 `tooling/make_ui_comparisons.py` 负责按固定映射生成对比图。若页面没有可见像素变化，也要保留该场景作为回归基线，并在图中明确写“保持一致”，不能把无变化误报为改动。
