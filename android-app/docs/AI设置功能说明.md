# AI 设置功能说明

> 版本：v1.214.0+227 | 更新时间：2026-08-14

## 当前产品结构

AI 设置主页只保留三个入口：

1. `AI 账号设置`：管理全部服务商和各自模型。
2. `用途分配`：只选择普通记账使用哪个服务商。
3. `隐私与数据`：查看本机存储说明并重置授权。

“高级参数设置”入口已移除。喵助手与报告不再在用途分配中单独配置。

## AI 账号设置

- DeepSeek 是内置预设，固定保留且不可删除。
- 右上角 `+` 可添加任意数量的 OpenAI 兼容服务商。
- 每个服务商独立显示为可折叠卡片，自定义服务商可删除。
- API Key、基础地址、服务名称和普通模型使用 App 统一透明输入样式。
- API Key 使用服务商稳定 ID 隔离保存；服务商元数据与备份不包含密钥。
- 自定义服务地址在填写 Key 后要求 HTTPS；本机 localhost 调试地址例外。

## 模型获取与管理

- 点击“获取模型”请求 `{baseUrl}/v1/models`；如果基础地址已经以 `/v1` 结尾，则请求 `{baseUrl}/models`。
- 请求方式为 GET，并携带 `Authorization: Bearer {API Key}`。
- 模型管理弹层显示模型数量，每行可删除；“从上游获取”会增量加入新模型，不恢复本次已删除的项。
- 点击“保存”后只保留筛选结果；服务商卡的普通模型字段改为从保留列表中选择。
- 模型身份是 `(providerId, model)`，不同服务商可安全保留同名模型。

## 用途分配

- 只保留“普通记账”一项，用于一句话记账、截图识别等结构化记录解析。
- 未配置 API Key 的服务商不可选。
- 喵助手与报告生成不读取旧的 chat/report 路由设置，统一跟随喵助手输入框当前模型。

## 喵助手模型与 Effort

- 输入框左侧模型按钮展示当前服务商和模型。
- 弹层按服务商分组展示所有已配置 Key 且已保留的模型。
- 点击模型立即写入 `chat_current_provider_id` 与 `chat_current_model`，下一条消息立即使用；重启后保持。
- Effort 提供关闭、Minimal、Low、Medium、High、Max 六档；报告与喵助手使用同一档位。
- 删除当前服务商后自动回退到其他可用服务商。

## 闲聊、查账与记账

- 输入先在本机分为记账、查账、闲聊三类。
- 只有明确记账才发送给“普通记账”服务商做金额和分类提取。
- 查账使用当前喵助手模型，并附带必要的账本上下文。
- 闲聊和知识问答使用当前喵助手模型，不附带账本上下文，也不会先发给普通记账服务商。
- 切换实际接收数据的服务商会重置隐私授权；同一服务商内切换模型不重复要求授权。

## 数据兼容与备份

- 旧 DeepSeek 和单一自定义服务配置会迁移为内置 `deepseek` 与 `legacy-custom` 服务商。
- 旧配置键继续保留必要的降级兼容，但不再控制喵助手/报告实际路由。
- 完整备份保存服务商名称、地址、模型列表和当前选择，不保存任何 API Key。

## 真机验收建议

1. 在 AI 账号设置中新建两个自定义服务商，分别保存 Key、地址并获取模型。
2. 关闭并重开 App，确认服务商、模型筛选结果和当前聊天模型都保持。
3. 在喵助手模型菜单中选择不同服务商的模型，立即发送“你好”和“法国人口有多少”，确认使用新模型且没有生成账单。
4. 发送“午饭 28”，确认仍走普通记账服务商并生成记账卡。
5. 生成报告，确认与喵助手使用相同服务商、模型和 Effort。
6. 删除当前自定义服务商，确认自动回退；确认 DeepSeek 没有删除入口。
