# 肥喵记账 · 项目文档

这是项目**唯一的**管理文档目录。仓库是真相源，Obsidian 里的「记账app/项目文档」是自动镜像。

## 文件一览

| 文件 | 管什么 | 更新频率 |
|---|---|---|
| [01-项目总览](01-项目总览.md) | 产品定位、范围、锁定决策、谁拍板、代码地图、数据治理 | 方向变了才改 |
| [02-项目进度](02-项目进度.md) | **当前版本/分支/线上状态**、待办、验证债务、风险、路线图 | 每批必改 |

## 新会话/新人从哪读

1. `02-项目进度.md`：现在在哪、下一步做什么；
2. `01-项目总览.md`：哪些决定不能推翻；
3. `04-开发规范.md`：怎么干活；
4. 按任务再读 03 / 05 / 06 / 07 / 08 / 09；
5. `10-更新日志.md` 看顶部最近几条就够。

## 冲突时听谁的

1. 用户最新明确的指令（当批结束时写回文档）；
2. 金额和统计听 `07`，视觉听 `06`，预算资产数据听 `08`；
3. 当前代码事实优于过时的文档描述，但发现不一致必须当场修正文档；
4. `参考资料/` 和旧聊天记录不能推翻上面任何一条。

## 规矩

- 只维护这一个目录，**不要再在别处新建交接文件、任务书、报告**。临时结论并进上表对应的文件。
- 每个批次至少更新 `02` 和 `10`；其余按 `04-开发规范.md` 第 7 节。
- 改完运行同步（仓库根目录）：

```bash
python docs/sync_obsidian.py          # 镜像到 Obsidian：记账app/项目文档/
python docs/sync_obsidian.py --check  # 只检查是否一致
```

- 不要在 Obsidian 里改这些文件，下次同步会被覆盖。
- 根目录 `CLAUDE.md`（Claude Code 读）和 `AGENTS.md`（Codex 读）内容相同，只是指向本目录的短入口，改一份就同步另一份。
